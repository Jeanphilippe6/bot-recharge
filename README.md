# Bot Telegram - Recharge PCS & Transcash

Bot Telegram de gestion de vente et d'échange de coupons de recharge PCS et Transcash contre paiement Mobile Money (XOF).

## Fonctionnalités
- Sélection du type de coupon (PCS / Transcash)
- Choix de la tranche de montant et conversion automatique en XOF
- Transmission sécurisée du code de recharge vers l'administrateur
- Interface d'approbation admin (Code Valide / Invalide)
- Réception du numéro de dépôt du client et confirmation de paiement

## Configuration requise
- Python 3.10+
- `python-telegram-bot==20.8`
